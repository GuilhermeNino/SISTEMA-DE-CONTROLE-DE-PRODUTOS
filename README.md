# Sistema de Controle de Estoque



Um sistema via terminal desenvolvido em linguagem C para realizar o gerenciamento simples, rápido e eficiente de produtos em estoque, controle de quantidades e cadastro de itens.



## Tecnologias Utilizadas


- **Linguagem:** C



- **Compilador:** GCC (ou similar)



- **Bibliotecas Padrão:** `stdio.h`, `stdlib.h`, `string.h`


## Como Instalar e Executar


### Opção: Usando o Dev-C++ (Recomendado para iniciantes)



1. Faça o download e instale o [Dev-C++](https://sourceforge.net/projects/orwelldevcpp/).



2. Baixe o arquivo `main.c` deste repositório.



3. Abra o **Dev-C++**, vá em **Arquivo > Abrir** (ou pressione `Ctrl + O`) e selecione o arquivo `main.c`.



4. Para compilar e executar o programa de uma só vez, pressione a tecla **`F11`** (ou vá no menu **Executar > Compilar e Executar**).





## Exemplo de Uso ou Demonstração


O programa funciona via terminal interativo. O usuário insere o nome, preço e quantidade de 5 produtos, e o sistema calcula o valor em estoque de cada um e o total geral.


### Exemplo de execução no terminal:


```

...
```
